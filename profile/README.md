# Heterra

**Advanced spatial analysis. One lightweight GIS app.**

Heterra is free, lightweight software for exploring spatial heterogeneity, uncovering patterns, building predictions, and evaluating models—with interactive maps, charts, and guided tutorials for every method.

**前沿空间分析方法,一款轻量级 GIS 软件。**
Heterra 是一款免费、轻量的空间分析软件,用于探索空间异质性、发现空间模式、构建预测模型并评估模型表现。每种方法均配有交互式地图、统计图和引导式教程,并可导出适用于学术论文与研究报告的高质量图件。

🌐 **Website:** [heterra.github.io](https://heterra.github.io)

## Methods

| Category | Methods |
|---|---|
| Spatial heterogeneity | [Optimal parameters-based geographical detector (OPGD)](https://doi.org/10.1080/15481603.2020.1760434)<br>[Local indicator of stratified power (LISP)](https://doi.org/10.1080/13658816.2024.2437811) |
| Spatial pattern | [Geocomplexity (GC)](https://doi.org/10.1080/13658816.2023.2203212)<br>[Second dimension of spatial association (SDA)](https://doi.org/10.1016/j.jag.2022.102834)<br>[Second-dimension outliers (SDO)](https://doi.org/10.1080/13658816.2025.2580414) |
| Spatial prediction | [Generalized covariate field (GCF)](https://doi.org/10.1080/13658816.2026.2729719)<br>[Geographically optimal similarity (GOS)](https://doi.org/10.1007/s11004-022-10036-8) |
| Model evaluation | [Degree of spatial interpretability (DSI)](https://doi.org/10.1080/13658816.2026.2614335)<br>[Spatial information explained (SIE)](https://doi.org/10.1016/j.isprsjprs.2026.09.034) |
